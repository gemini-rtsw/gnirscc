This directory contains the source code and configuration files for the
Gemini NOAO Advanced Array Controller (GNAAC). The following types of file
are contained: 

*.c    - C source code

*.par  - Pvload parameter files

*.cmd  - Microcode command files

NOTE: There are two versions of the initVals.par and testVals.par
      parameters files. One version is used when GNAAC is used stand-alone
      and the other is used when GNAAC is installed as part of the NIRI
      system. Please make sure the correct version is present. (The
      other version will have been renamed xxx.par_GNAAC or xxx.par_NIRI).
