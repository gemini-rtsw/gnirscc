2.1.3.2
The housekeeping is a place where the current state of the hardware is kept.  
All of the voltages and temperatures of the controller are stored in 
housekeeping.  The housekeeping is initiatiated by firing of the ReadHK 
record.  This sends a message to the icon through the wfire message device 
driver.  The icon reads the housekeeping and sends the data back to the 
EPICS 68040.  When it receives the data, it places the data into a global 
array resident in local memory. This array is linked through EPICS to 
records that hold the current values in the database.  The reading of the 
housekeeping is automatically turned off when the array is being read, 
because it seems to cause noise in the image when it is read at the same
time an image is being taken.
