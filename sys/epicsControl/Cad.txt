


NAME: initCad
FUNCTION: Initialize the components controller software
INPUTS:
		simMode - pCad->a - epics simulation level
				values - (STRING) "NONE","VSM","FAST","FULL"

		hsimMode - pCad->b - hardware simulation level
				values - (STRING) "NONE","VSM","FAST","FULL"

OUTPUTS:
		carVal - pCad->valh - car state
				values - (LONG) CAR_BUSY(2),CAR_IDLE(0),CAR_ERROR(3),CAR_PAUSED(1)
EXTERNAL CALLS:
		setSimulation -  sets hardware simulation level
		vmeInit - called if epics sim is SIM_NONE - sets up low level softeware


GLOBAL VARS:
		noXYCOM - flag for xycom board presence in system
		noSenTorr - flag for sentorr in system


initCad
		The epics and hardware simulation are set from initCad.  

		epicsSim - This is useful for testing the epics interactions
						without touching any hardware.  

		hardwareSim - Sets the simulation level of the hardware.  If this is set
				to anything other than none, the low level code will simulate 
				the presence of the hardware.  
				When set to none, the motor control hardware is enabled.  
				However, there are three global variables that can be set
				which effect the simulation of the xycom, temp monitor board,
				and senTorr:
						noXYCOM
						noTempMon
						noSenTorr
				Set to one, the particular piece of hardware will not be used.

		Low level software flow
		hardware initialization - when hsim = NONE
			I. vmeInit
				A. spawn tasks
					1. initialize interrupt vectors
					2. gnirsInit
						a. vmeBoardInit
							1).motorDriverInit 
								a). create sem
								b). create ring buffer (for motor commands)
								c). set structures
							2). initXycom (noXYCOM,gnirsG.simulation)
								a). create sem
								b). set structures
							3). initTempBoards (noTempMon, gnirsG.simulation)
								a). create sem
								b). set structures
							4). initSenTorr (doesn't check noSenTorr)
								a). create sem
								b). open serial port
						b. testHardware 
							1).testOMSCards (gnirsG.simulation)
								a). send WY command (get oms version)
							2). motorOff (gnirsG.simulation)
							3). testXYCOM (noXYCOM, gnirsG.simulation)
								a). read id
							4). testTempBoards (noTempMon, gnirsG.simulation)
								a).  read temp board test points
							5) . testSenTorr (noSenTorr, gnirsG.simulation)
								a). send commands to senTorr
						c. mechDescInit
							1). build mech structures
						d. filterDescInit
							1). build mech structures
						e. read gnirsConfig
						f. read gnirsMechanisms
						g. read gnirsFilters
				
		possible errors
				hardware not present.  (oms, tempcard, dio)
				input to cad not one of:  "NONE","VSM","FAST","FULL"
			
 
Name:acqDatmCad cameraDatmCad coverDatmCad deckerDatmCad focusDatmCad fw1DatmCad fw2DatmCad slitDatmCad xdispDatmCad gratingDatmCad
FUNCTION:
		Datum a particular motor.  If hsim and sim are set to none, this will
		find the datum position on the motor and set the step counter to zero.
INPUTS:
				datumed - pCad->f - LONG
				simMode - pCad->g - LONG

OUTPUTS:	NONE
EXTERNAL CALLS:
				datumMech(int motor#);
GLOBAL VARS: 

		possible errors - no driver , home switch error, motor doesn't turn, 
						motor not hooked up

Software control flow
	I. initialization
		A. ?DatmCadInit
			1. create msg queue or semaphore
			2. start ctrl task
	II. MARK
		A. cad mark routine
	III. PRESET
		A. send datum msg to low level
	IV. CLEAR
		A. cad clear routine
			1. clear cad message field
	V. START
		A. set car busy
		B. start ctrl task	
			1. moveMech
				a. moveOneMotor
					1).  datum

Hardware testing
	I. Mechanisms
		A. Rotary
			1. FW1, Fw2, Camera, prism
			2. check datum for both home switches
			3. set parameters in config file
				a. distance between switches.
				b. total distance
				c. acc, velocity
				d. backlash
				e. focus shift
				f. position locations and names
		B. Linear
			1. Acq, Decker, Slit
			2. check datum for both home switches
			3. set parameters in config file
				a.  distance between home switches.
				b.  total travel
				c.  acc, velocity
				d. dist between hard and soft limits
				e. backlash
				f. focus shift
				g. position locations and names
			6. test limit switches
			7. repeatability of positions
		C. grating,
			1. check datum for both home switches
			2. distance between home switches.
			3. total travel
			4. acc, velocity
			5. calculations for grating angle (order wavelength)
			6. range of wavelengths
			7. dist between hard and soft limits
			8. backlash
			9. focus shift
			10. position locations and names
		
	II. Cryo Control
		A. manual switch display in EPICS
		B. state display in epics
	III. temperature readback
		A. temperature probe offsets
	IV. pressure readback
